# Aporia 核心玩法重设计方案

## 诊断：为什么现在不好玩

当前游戏的根本问题不是缺少哲学深度，而是**玩家没有主体性**。现在的流程是：走 → 读文本 → 选按钮 → 数字变化 → 重复。坐标变了，但玩家的处境没变。clarity/strain 是数值，不是感受。Lens 是滤镜，不是工具。判断（affirm/negate/sublate）是选择题，不是思辨。

核心原则：**哲学不应该是被读的，而应该是被做的。玩家应该在不知道 Aufhebung 这个词的情况下，完成一次 Aufhebung。**

---

## 一、核心资源系统：用活你已有的东西

### 1.1 Clarity（清明）→ 重设为生命值 + 视野

Clarity 不再是被动累积的分数。它是你的**感知半径**和**生存条件**。

- Clarity 范围：0-8。起始值 = 2。
- Clarity 决定你在 TUI 屏幕上**能看到多少文字**。Clarity=2 时，屏幕上只有中心 3 行文字可见，四周全是 `░` 和 `▓` 的迷雾。Clarity=6 时，整个空间的文本、符号、隐藏路径都清晰可见。
- **Clarity=0 即死亡**（坐标归零，回到 Beginning，loop+1）。这就是 permadeath 在永恒轮回里的等价物：你不是"死了"，而是**遗忘了一切，被迫重新开始**。但 Traces 会留下。

### 1.2 Strain（压力）→ 重设为腐蚀/熵

- Strain 范围：0-8。起始值 = 0。
- 每次你做出判断、使用 Lens、阅读碎片、在 Echo 中逗留，Strain 都会上升。
- **Strain >= Clarity 时，触发"意识形态固化"**：你的坐标被锁定 30 秒，无法移动，无法切换 Lens，屏幕上反复闪烁你当前意识形态对应的教条文本。这不是惩罚——这就是**虚无主义回环**的体验化。
- 降低 Strain 的唯一方法：**扬弃**（见下文 2.3）或回到 Beginning 重置（但会丢失部分 Clarity）。

### 1.3 符号（Symbols）→ 重设为可组合的钥匙

当前符号只是 flag（解锁了就完事）。重设计：

- 符号是**可消耗的**。用一个符号打开一条路径后，这个符号会变为 dim 状态（◇），在本轮不可再用。
- 但下一轮循环中，dim 符号会以 Trace 形式出现在世界里，可以重新捡起。
- 关键机制：**符号可以组合**。`there` + `is` = 通过 Echo 的门。但 `not` + `there` = 一条完全不同的隐藏路径，通向 Echo 中一个只在第二轮以后才存在的密室。
- 符号组合遵循辩证逻辑：`being` + `nothing` → 自动合成 `becoming`（这就是扬弃的机械化表达）。玩家第一次看到这个组合时，不会被告知"这是黑格尔的存在论"——他只是看到两个矛盾的符号碰在一起，产生了第三个新的东西。

## 二、哲学即机制：三大核心操作

### 2.1 否定（Negate）→ 实际操作：擦除

按 `N` 键进入否定模式。光标变为 `×`。你可以**擦除屏幕上的任何一行文本**。

被擦除的文本不会消失——它变成反色/暗色的**残影**（Schein / 假象）。残影文本：
- 不再阻挡路径（如果那行文本原本是一堵墙）
- 但会持续产生 Strain
- 在下一轮循环中，残影会以扭曲的形式重新出现

**这就是黑格尔的规定性否定**：否定不是消灭，而是将存在转化为本质的假象。玩家会逐渐发现：盲目擦除一切会让世界充满残影，Strain 飙升，视野被假象污染。

### 2.2 肯定（Affirm）→ 实际操作：铭刻

按 `A` 键进入肯定模式。你可以在世界中**写入一个符号**，将其固定在当前位置。

- 铭刻的符号在本轮循环中不会消失
- 其他玩家（或下一轮的自己）能看到这个铭刻
- 但铭刻会消耗 Clarity（你付出了清明来确认某物的存在）
- 铭刻在错误的位置会产生矛盾——如果你在一个位置铭刻了 `ground`，但那个位置的本质是 `abyss`，矛盾会导致空间裂变，开启一条新路径（也可能是死路）

### 2.3 扬弃（Sublate / Aufhebung）→ 实际操作：折叠

这是最强大也最危险的操作。按 `S` 键选中两个**矛盾的元素**（一个肯定的铭刻 + 一个否定的残影，或两个对立的符号），然后按 `Enter`。

如果两个元素构成真正的矛盾（而不是随机配对），它们会**折叠**成一个新的、更高阶的符号或路径。同时：
- Strain 大幅下降（矛盾被解决了）
- Clarity 小幅上升
- 新符号/路径只在本次扬弃后出现

**错误的扬弃**（两个不构成矛盾的元素强行折叠）会导致 Strain 暴涨 + Clarity 暴跌。这就是为什么扬弃是技能表达最强的操作——你必须**真正理解**两个概念之间的关系。

## 三、八章重设计：每章一个核心谜题类型

### Beginning（开端）—— 迷宫定向

四个方向不再等价。每个方向对应一种意识形态起点（d4 坐标）：
- 北 = 服从（d4=1），南 = 抉择（d4=2），东 = 创制（d4=3），西 = 泰然任之（d4=4）
- 第一次玩时你不知道这些。第二轮你会在起点看到上一轮自己留下的 Trace："上次你向北走了。你循环了。"
- **隐藏机制**：如果你在起点站立不动 15 秒，会看到十字中心有一道极淡的裂缝。这道裂缝只有 Clarity >= 4 时可见。通过它可以直接跳到 Grounding（跳过前半程）——但你会带着极少的符号进入后半程，存活几率极低。这就是**高风险快速路线**。

### Echo（回响）—— 节奏谜题

回环不再是"走来走去找暗门"。回环是一个**节奏型的文本迷宫**。

屏幕上有一段文本在循环滚动（代表虚无主义回环）。文本中隐藏着四个"裂缝字符"（用微妙的颜色差异或 Unicode 变体标记）。玩家必须在裂缝字符经过屏幕中心时按 `Enter`——**时机对准**才能打开暗门。

这是一个 timing puzzle：
- 第一个裂缝很容易抓（训练玩家）
- 第四个裂缝的窗口极短，且文本滚动速度会在你按下前三个后加快
- 如果你连续失败 3 次，文本会变化——回环在"回应"你的失败，给出新的提示

这就是"虚假回环"的机械化：玩家真的在体验重复，真的在尝试打破它。不是读到"这是虚无主义的循环"，而是**困在其中**。

### Foresight（前瞻）—— 碎片拼图

前瞻空间是一片开阔的文本场。屏幕上散布着 15-20 个文本碎片（荷尔德林的诗句碎片 + 哲学命题碎片）。但它们的**显示顺序是错的**。

玩家需要用方向键移动光标，用 `A`（肯定）固定一个碎片的位置，用 `N`（否定）将一个碎片标记为"不属于这里"。

当碎片被正确排列时，它们会组合成一段完整的文本，揭示 Leap 井道的开启条件。但这不是简单的拼图——碎片的"正确顺序"取决于你的当前坐标（d1-d4）。不同意识形态视角下，同一组碎片的正确排列方式不同。

**Aha 时刻**：玩家在第一轮用 [1,1,2,1] 坐标排好了碎片，但第二轮坐标变成了 [2,3,2,1]，发现上次的排列完全不对——同一组文本在不同视角下有不同的"正确"解读。**这就是透视主义**，但玩家是通过失败和重排来体验的。

### Leap（跳跃）—— 信仰赌博

跳跃不是"按按钮就跳"。它是一个**盲选**。

屏幕变黑。只剩三行文字：

```
你站在井道边缘。
下方是 ████████ 。
[J] 跳入    [H] 返回前瞻
```

`████████` 的内容取决于你在 Foresight 中读过多少碎片、带了什么符号。如果你准备充分，`████████` 会部分显示（比如"下方是 ██根据██"）。如果你完全没准备，它是全黑的——你真的是在盲跳。

跳入后有三种结果：
1. **有足够符号 + 高 Clarity** → 安全到达 Grounding
2. **符号不足但 Clarity 足够** → 到达 Grounding 但 Strain 暴涨（你受伤了）
3. **Clarity < 3** → 死亡，回到 Beginning，但你会获得一个 Trace："井道下方是......"

**这就是克尔凯郭尔的信仰之跃**：不是读到"需要信仰"，而是真的面对未知做出不可撤回的选择。

### Grounding（建基 / 离基深渊）—— 矛盾解构

这一章的核心谜题是**找到并扬弃三对矛盾**：

空间中散布着 6 个概念铭刻（用 `$` 符号标记的 Lens 节点）。它们两两构成矛盾对：
- `Substance` vs `Causality`（实体 vs 因果）
- `Identity` vs `Difference`（同一 vs 差异）
- `Form` vs `Content`（形式 vs 内容）

玩家必须找到每一对，用 Sublate 操作折叠它们。每次成功的扬弃会让地面更稳固（可见空间扩大）。三对全部扬弃后，地面完全显现——但显现的是一道裂缝，不是一个地板。

**如果扬弃顺序错误**（比如先折叠 Form/Content 再折叠 Identity/Difference），裂缝会以不同的方式打开，通向不同的 Seyn 变体。这给了 speedrunner 和重玩者一个发现空间。

### Seyn / Ones to Come / Last God —— 终章三连

这三章保持相对简洁，因为它们的力量在于**减法**：

- **Seyn**：整个屏幕只有一扇门和你的坐标。门上的条件是动态的——它每 5 秒变化一次。你必须在门的条件与你的坐标恰好吻合的瞬间按 Enter。错过了就等下一次。Strain 在等待中缓慢上升。这就是"保留"（Withholding）的体验化。

- **Ones to Come**：你的坐标开始自动向 4444 漂移。每秒一个维度 +1。你可以用否定操作（N）**阻止某个维度的漂移**，但你最多只能同时阻止 2 个维度。你必须选择**让哪些维度变异，保留哪些**。这是一个实时决策压力谜题。到达 4444 是"成神"，但如果只有部分维度到达 4 则是"分裂"——不同的最终坐标组合导向不同的 Last God 体验。

- **Last God**：保留 300 秒锁定。但增加一个关键机制：在 300 秒内，屏幕上会以极慢的速度逐字显示一段诗。每 30 秒左右会有一个瞬间，一个字符会闪烁。如果你在那个瞬间按任意键，你会"打断沉默"——Strain 归零，但你会跳过最终的启示文本，直接回到 Beginning。如果你 300 秒内**一次都不按**，你会获得一个独特的 Trace（每轮不同），并且下一轮 Beginning 中十字中心的裂缝会更明亮。**真正的耐心是这个游戏的终极技能。**

## 四、Lens 系统重设计：不是滤镜，是武器

Lens 不再只是"换一种方式看文本"。每个 Lens 提供一种**主动能力**：

- **$-1-1（纯粹思维）系列 Lens**：装备后，你的否定操作可以穿透两层文本（擦除背后还有一层隐藏文本）
- **$-1-3（本质）系列 Lens**：装备后，残影文本会显示为可读的（你能看穿假象）
- **$-2-2（概念）系列 Lens**：装备后，扬弃操作的成功容错率提高（配对不需要精确矛盾，近似矛盾也可以）
- **$-2-4（理念）系列 Lens**：装备后，你可以在 Last God 阶段看到额外的隐藏诗句

Lens 的获取方式：在特定场景中完成扬弃操作时，有概率解锁对应 affinity scene 的 Lens。**Lens 跨轮回保留**——这是永恒轮回中最重要的"进度"。

## 五、每轮循环为什么不同

1. **Trace 系统**：前一轮你在世界中铭刻的符号、擦除的残影、留下的脚印，都会以淡灰色出现在下一轮中。你可以选择跟随或忽略自己的过去。
2. **坐标依赖的谜题变体**：Foresight 的碎片排列、Grounding 的矛盾对、Seyn 的门条件都取决于你的坐标。不同的起始方向 → 不同的坐标演化 → 不同的谜题。
3. **符号消耗与重获**：你在上一轮消耗的符号变成 dim Trace，散布在世界各处。捡回它们需要走不同的路线。
4. **Loop count 影响世界状态**：第 1 轮 Echo 中的文本是简单的回环。第 3 轮 Echo 中的文本会包含前两轮你在 Echo 中做过的选择的回响。第 5 轮 Echo 会出现一个"你"的残影在回环里永远走不出去。

## 六、核心循环总结

| 时间尺度 | 玩家在做什么 |
|---------|------------|
| **每 5 秒** | 移动光标、阅读可见文本、观察 Clarity/Strain 变化、决定是否否定/肯定眼前的东西 |
| **每 30 秒** | 决定是否使用一个符号打开路径、是否切换 Lens、是否尝试一次扬弃、是否后退降 Strain |
| **每 5 分钟** | 完成一个章节的核心谜题、获得新符号或 Lens、做出不可逆的路径选择 |
| **每 20-30 分钟** | 完成一轮循环、回到 Beginning、看到 Trace、决定下一轮走哪条路 |

**"再来一轮"的钩子**：
- 我上一轮没解锁那个 Lens，这次走不同路线试试
- 我在 Grounding 发现了一个没见过的矛盾对，扬弃后会通向哪里？
- 我上次在 Last God 没忍住按了键，这次我要撑满 300 秒
- 我的 Trace 显示了一条我从没走过的路，那里有什么？
- 我想试试 [4,1,3,2] 坐标下 Foresight 的碎片会排成什么样

---

## 七、实现优先级

1. **P0（立刻做）**：Clarity 视野系统 + 死亡/重置机制 + Echo 节奏谜题
2. **P1（第二周）**：否定/肯定/扬弃三操作 + 符号消耗/合成
3. **P2（第三周）**：Foresight 碎片拼图 + Grounding 矛盾解构 + Leap 盲跳
4. **P3（第四周）**：Lens 主动能力 + Trace 跨轮回显示 + Ones to Come 实时漂移
5. **P4（持续迭代）**：坐标依赖的谜题变体 + Loop count 影响世界状态

这个优先级的逻辑是：先让游戏有**生死**和**节奏**，再让它有**深度**和**发现**。
