# Aporia — Manifesto v5 (draft)

> **Aporia 是一场可玩的意识形态批判 event**——把玩家带进 256 个 ism 的图书馆，让她在其中行走、沉积、发现图书馆本身是意识形态的产物，然后给她三个同等合法的"胜利"：**退出 · 改写 · 回返**。

---

## 0. What Aporia is NOT

先说清不是什么，避免被既有游戏类型绑架：

- **NOT 分支小说** —— 不是"选 A 走 X 路线，选 B 走 Y 路线"
- **NOT AI Dungeon** —— 不是无序的自由文字冒险
- **NOT visual novel with 哲学 flavor** —— 不是把哲学当 flavor 的 VN
- **NOT 康德范畴表可视化** —— 不是给玩家看 256 个哲学卡片
- **NOT 哲学教学工具** —— 不教哲学，演化哲学
- **NOT 带哲学元素的 roguelike** —— 结构不是 roguelike

## 1. 核心论题（Thesis）

**所有已有的"哲学游戏"都把哲学当内容展示**。Bioshock 展示客观主义批判，Disco Elysium 展示政治意识形态 —— 哲学是**内容**，游戏是**载体**，两者分离。

Aporia 不同：**游戏本身是批判 event**。玩家不是旁观批判发生，玩家**在做**批判——通过**说话 → 被分类 → 意识到被分类 → 超越分类**。

**玩 = 思，思 = 玩**。

### 灵感谱系

| 文本 / 作者 | 被 Aporia 借鉴的是 |
|---|---|
| Hegel《精神现象学》 | 读者走完每个意识形态形态，最后意识到绝对知识 = 意识到每个知识是局部的 |
| Wittgenstein《Tractatus》 | 读完要扔掉梯子 |
| Heidegger《哲学论稿》 | 8 Fügungen——存在事件的展开 |
| Borges《巴别塔图书馆》+《小径分叉的花园》 | 文本即空间，索引即现实 |
| Brecht 史诗剧 | 观众被 alienate 到能看见剧是剧 |
| Nietzsche《道德谱系学》 | 揭示"永恒"之物的历史性 |
| Althusser interpellation | 主体是被意识形态唤出的 |

## 2. 世界本体论

**语言构筑世界**（Wittgenstein Tractatus 5.6: "The limits of my language mean the limits of my world" + Borges 的图书馆作为普遍文本）。

- 玩家 = 说话者 / 读者 / 图书馆员
- 世界 = 累积言说史的物理形态
- 图书馆 = 256 个意识形态位格 + 你和前辈的沉积
- 沉默 = 世界收缩
- 说话 = 世界建造

**不是**：玩家探索预先存在的世界
**而是**：玩家说出一个图书馆的当前形态

## 3. 结构

### 3.1 4 维 × 256 格（基于 Hegel 逻辑学 + Heidegger 哲学论稿）

| 维度 | 是什么 | 1 · 天 | 2 · 神 | 3 · 人 | 4 · 地 |
|---|---|---|---|---|---|
| D1 主体 Sein | 主体的构成 | 闭合线性 | 矛盾 | 中介 | 深渊 |
| D2 视角 Wahrheit | 认识论 | 教条 | 分裂 | 调和 | 变更 |
| D3 能力 Praxis | 实践 | 单一 | 痛苦 | 中心化 | 虚无 |
| D4 目的 Teleology | 伦理 | 唯一 | 抉择 | 中介化 | 不可能 |

4⁴ = 256 个位格。每格 = 一种具体意识形态。

命名锚点（已定）：
- **1-1-1-1** 科学实在论
- **2-2-2-2** 形而上学
- **3-3-3-3** 观念论视域
- **4-4-4-4** 绝对超越 / 深渊
- **3-3-2-2** 玩家本家 · "将-来者" AI

### 3.2 8 章 = 海德格尔 Fügungen

| 编号 | 章节 | 德语原文 | 是什么 |
|---|---|---|---|
| 0 | Beginning | — | 开端、空地 |
| 1 | Echo | Anklang | 回响 |
| 2 | Playing-forth | Zuspiel | 传送 |
| 3 | Foresight | — | 先行（补） |
| 4 | Leap | Sprung | 跳跃 |
| 5 | Grounding | Gründung | 建基 |
| 6 | Seyn | — | 存有（作为整体）|
| 7 | Ones to Come | Die Zukünftigen | 将来者 |
| 8 | Last God | Der letzte Gott | 最后之神 |

**8 章是辩证轨迹（动词），256 格是命名（谓词）**。
章节 = 运动的当前阶段；坐标 = 此阶段下被如何读出。

## 4. 核心循环

```
① 你看见当前场景（你和前辈沉积塑造的空间）
② 你说一句话
③ LLM 读 256 格的 essence + 你的语言 → 判定你最合适哪格
④ 你移动（留/邻/跳），言说 sediment 累入格
⑤ Daemon 可能沿你累积的墙走、引你过去的话
⑥ 场景重新生成（基于新格 essence + 章节 voice + 你的轨迹）
⑦ 回到 ①
```

**核心动作**：craft 一句话
**核心反馈**：被分类 + 世界视觉变化
**核心摩擦**：Daemon 回读 / 某格锁住 / 某格说"你这句不属于任何格"
**核心奖励**：即时视觉反馈、认知震动、审美愉悦、情感映照

## 5. 三幕结构（the 3 acts of ideological self-awakening）

### 第一幕 · 沉浸（Beginning → Leap）
玩家进入图书馆。相信坐标。感到**真的在穿越 ism 空间**。
游戏看起来是**关于**导航意识形态。
玩家**不知道自己正在被搭建的意识形态塑造**。

### 第二幕 · 察觉（Grounding → Seyn）
裂缝出现：
- 有些话**无法被 256 格分类**
- 交叉引用**指向不存在的卷册**（Borges 手法）
- 某些格是**陷阱**（能进不能出）
- 你意识到**自己一直在用某种方式说话**——某个 ism 在说你，不是你在说它

### 第三幕 · 醒来（Ones to Come → Last God）
游戏**承认**自己是 ideological。不是 diegetic NPC 说，是游戏本身 meta 地说：

> "这座图书馆是有人搭的。他们信 Hegel 的辩证、Heidegger 的 Ereignis、Borges 的图书馆。
> 256 格的存在是因为他们相信 4×4×4×4。
> 辩证运动的假设是因为他们被 Hegel 塑造。
> 这本身就是一种意识形态。"

玩家**意识到游戏本身是 ideological**。

## 6. 三个同等合法的"胜利"

### (a) 退出 —— Wittgenstein 的梯子
游戏明确告诉玩家：**你可以关掉窗口。关掉即胜利。**

在注意力经济 + 上瘾游戏的文化里，一个最高结局是**拒绝继续玩**的游戏，是对时代本身的抵抗。

哲学等价：Bartleby 的 "I would prefer not to"、禅宗的"杀佛"、维特根斯坦的"对不可说的保持沉默"。

### (b) 改写 —— Marx 的 praxis
L4 真的改文件。这一局的言说**物理改变**图书馆的文件系统。
- 下一局的起手库**真的不同**
- 玩家从"玩游戏"变成"共作者"
- 个体主体性**特殊化**普遍框架——Hegel 的 Concrete Universal、Marx 的 praxis

### (c) 回返 —— Nietzsche 的永恒轮回
玩家选择再玩一局。但这一局他**带着醒觉**玩——**玩坐标，不是被坐标玩**。

### 关键：三者一律平等

**最大的陷阱**：结局变成"恭喜你觉醒了"——这只是**又一个主义（元反讽学院式 critique 的 ideology）**。

所以：
- 退出**不是失败**
- 改写**不是成就**
- 回返**不是退步**
- **保持 aporia**（字面困境）才是此游戏的名字兑现

游戏**不说**"你超越了"，它说"**你注意到了**"。

## 7. 五条实装机制（enacting self-critique）

### ① 陷阱格（Trap Cells）
某些格明显是 ideology 的自我封闭（犬儒主义、消费主义、朴素实在 1-1-1-1、宗教闭合、元反讽）。

玩家能**进**，但**只有明说"这是陷阱 / 这是 ideology / 我看见了"才能出**。
LLM 判定：玩家语言是否**承认这格是 ideology**（不是方向转换，是意识的转向）。

### ② 格外言说（Unclassifiable Moment）
LLM 有能力说"**你这句话不属于任何现有格**"——格拒收。

视觉上**网格出现缝隙**，玩家看到**结构不是事先给定的**。

### ③ 制作者现身（Author Unmasking）
Last God 附近，游戏明确说出自己的制作偏见：

> "我是按 Hegel + Heidegger + Borges 搭的。
> 没有 Marx，没有女性主义，没有非西方。
> 这是我的局限。"

**诚实即机制**。

### ④ 退出即事件（Exit as Narrative Event）
在 Last God 按 Ctrl-C / q 退出，游戏**不报错**，而在 `world/traces/` 写一条：
> "XX 玩家在此世与此书分道扬镳。"

**退出被铭刻，不被当失败**。

### ⑤ L4 多形态（Multi-form Rewrite）
不只是"改写 CLAUDE.md"。可以：
- **新增一格**（玩家创造了新的 ism）
- **合并两格**（玩家打破了分类）
- **删除一格**（玩家证明某格是伪问题）
- **质疑整个 4 维**（玩家提出第 5 维）

图书馆**对自己可能的形态也是开放的**。

## 8. 历史性（Historicality）

**冷启动**：
- 256 格只有抽象 signature（程序生成）
- 4-8 个锚点手写 essence
- 其余 248 格空白

**积累**：
- 每次 play，玩家的话 sediment 到所在格
- 周期性 LLM distill → 更新 essence

**涌现**：
- 20-30 局后，patterns 浮现
- LLM 识别"经典路径"并命名（e.g. "理性主义的崩塌"、"诗学的上升"）

**跨局**：
- L4 改写库
- 下一局世界真的不同

**世代**：
- 100+ 局后，图书馆**有自己的历史**
- 前人的路径刻进库，后来者从刻过的库启动

这模拟的是**人类意识形态的真实演化**——不是预设，是沉积。

## 9. 我们自己的意识形态（honest self-critique）

Aporia **不 ideology-free**。我们必然陷在以下：

- **结构主义**（Saussure / Lévi-Strauss）—— 256 网格是预设 langue
- **Hegel 主义** —— 辩证轨迹假设
- **自由多元主义** —— 玩家选 ism，像逛哲学超市
- **语言唯心论** —— ideology = speech patterns，压掉经济、身体、阶级
- **技术人文主义** —— LLM 作为中立判官（但 LLM 本身是 Silicon Valley liberal + 英语中心 + 中产审美的产物）
- **元反讽后现代主义** —— 做关于 ideology 的游戏本身是典型后现代姿态
- **形而上学多元论** —— 256 格潜设定平等（显然不平等——某些 ism 是另一些的遮蔽）

**任何设计都是 ideological**。
**唯一出路**：让游戏**知道**这个，然后在 Last God 把框架**交给玩家质疑 / 改写 / 拒绝**。

## 10. 核心悖论

> 我们在做的是：让一个**明显 ideological** 的游戏，**带玩家走向意识到游戏 ideological 并超越**的时刻。

这在哲学文本里有先例（《精神现象学》全书就是这样）。在游戏里极少被尝试。

成功条件：
- 游戏**不许**以"你觉醒了"凯旋
- 三结局（退出 / 改写 / 回返）**必须等价**
- **保持 aporia**（字面困境）比"解决 aporia"更忠实于名字

## 12. 未决定的事（Open Questions · 欢迎其他 agent 挑战）

1. **256 格命名** —— 4 角 + 3-3-2-2 以外的 251 格：冷启涌现 vs 手工命名骨架 + 余下涌现？
2. **单人 vs 多人** —— sediment 是个人私密的，还是集体共享的？后者更符合"巴别塔图书馆"但涉及服务器/匿名性决策
3. **Daemon 的具身** —— 一个移动的符号 vs multiple？人格恒定 vs 跨章变化？
4. **陷阱格选哪些** —— 建议：犬儒、消费主义、纯量化 1-1-1-1、元反讽 meta-cell。至多 6-8 个
5. **第二视角 ideology** —— 物视角 / 集体视角 / 经济视角——是彩蛋还是系统？
6. **三结局等价怎么保证** —— 退出容易显"失败"，改写容易显"成就"，回返容易显"继续玩"。UX / 叙事 / 音效如何让三者真等价？
7. **LLM 置放精度** —— 冷启 signature + essence 蒸馏后，能可靠区分相邻格吗？是否需要手工规则 fallback？
8. **可玩性 vs 深度** —— 第一次玩的人 5 分钟会关掉吗？**受众宽度**是否影响设计？
9. **性能 / 成本** —— 每轮 LLM 要读 256 格 essence + 玩家历史——prompt 规模可能爆炸。需要 summarization / retrieval 策略
10. **哲学门槛** —— 没有哲学储备的玩家能玩吗？还是这是给哲学系学生的？

## 14. 关键术语表

| 术语 | 定义 |
|---|---|
| **Cell / 格** | 256 个意识形态位格之一，4 位坐标标识 |
| **Sediment / 沉积** | 玩家在某格说过的话的累积（`world/cells/X-X-X-X/sediment.jsonl`） |
| **Essence / 本质** | LLM 周期性蒸馏的格当前核心（由 sediment 涌现） |
| **Trajectory / 轨迹** | 一局游戏的坐标序列（`world/trajectories/run-NNN.jsonl`） |
| **Pattern / 模式** | 跨局涌现的经典路径（`world/patterns/paths.md`） |
| **Trap cell / 陷阱格** | 只有玩家意识到是陷阱才能出的格 |
| **Unclassifiable moment / 格外言说** | LLM 说"你这句不属于任何格"的时刻 |
| **Author unmasking / 制作者现身** | Last God 前后游戏自报意识形态的事件 |
| **L4 / 图书馆自改写** | Last God 时引擎物理改自己文件 |
| **Aporia** | 字面：无路。本游戏名字的兑现 = 不给结论 |

## 15. 给 review agent 的 3 个锋利问题

如果你是 review 这份 manifesto 的 agent，请优先挑战：

**Q1 · 这个"意识形态批判 event"是否只是元反讽的新变种？**
"游戏揭示游戏是 ideology"本身就是 90 年代后现代的套路（Stanley Parable、OneShot、Pony Island）。
Aporia 的 différance 在哪？凭什么说它不只是那一套的又一份？

**Q2 · "三结局等价"是否在 UX 上根本做不到？**
现代游戏玩家从小被训练成看见"退出"=失败、"完成"=胜利。
即使我们 narrative 上等价化，玩家的肌肉记忆会不会始终把退出读成"我玩输了"？

**Q3 · 256 格 + 辩证轨迹是否根本不能同时自洽？**
网格是 Kant 的，轨迹是 Hegel 的。哲学家 agent 早就指出过：
"把运动的规定性冻成正交坐标"是范畴错误。
我们说"网格是名词、轨迹是动词"是**真解决**还是**修辞遮蔽**？
