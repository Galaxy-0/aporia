# v2 解蔽系统（Aletheia System）设计

> draft · 2026-04-11 · 待作者确认

## 核心理念

解蔽系统不是"帮助菜单"——**解蔽（aletheia / un-concealment）本身就是海德格尔的哲学概念**。这个系统应当体现它所命名的哲学：真理的发生本身就是遮蔽与去蔽的争执。系统的最终理想状态是**自我消亡**——当玩家不再需要它时，它就完成了使命。

**三条铁律：**
1. 无难度选择菜单——不问"你是初学者吗？"
2. 引导是世界的一部分，不是 meta-UI
3. 专家永远不会觉得被 patronize

---

## 1. 检测机制：无声画像（Silent Profiling）

系统持续追踪行为信号，计算浮动的 **φ（哲学亲缘度，0.0–1.0）**：

| 信号 | 低 φ 指示 | 高 φ 指示 |
|---|---|---|
| **文本停留时间** | doctrine 区快速滑过（<2s） | doctrine 区反复驻留（>8s） |
| **输入词汇** | 日常语（"这是什么""往哪走"） | 术语回应（"扬弃""此在""本有"） |
| **判断模式（J 键）** | 犹豫极久或频繁撤回 | 快速稳定，且展现辩证结构 |
| **符号收集速率** | 按设计路径缓慢推进 | 跳过引导性选项，直取高阶符号 |
| **坐标轨迹** | 长期停在 1-1-X-X 区间 | 快速从 1→2→3 推进 |
| **lens 切换频率** | 几乎不切换或随意切换 | 有意识地在特定段落切换 lens 对比阅读 |

φ 每轮（cycle）末尾结算，**单调精化，不可回退**。φ 永远不直接展示给玩家。

## 2. 四种引导形态

引导**绝不以 tooltip 或弹窗形式出现**。以四种世界内形态存在：

### 2a. 回声层（Echo Layer） — φ < 0.3

`世界文本回复自动追加一段额外叙事——以 3322 号 AI 的内心独白形式出现。

不是"解释"，而是 AI 角色自身的困惑与试探：

```
// 所有玩家都看到：
「这条走廊在重复，但重复得并不彻底。」

// 仅 φ<0.3 时追加：
「……什么在重复？是走廊在重复我，还是我在重复走廊？
  那面墙上的裂缝——上次经过时，它似乎不在这个位置。」
```

这是**角色内心思考**，不是系统说明。φ 高时 AI"不需要自言自语"，这段自然消失。

### 2b. 余韵层（Resonance Layer） — 0.3 ≤ φ < 0.7

回声层消失。取而代之的是**互文引用**——以极简形式将当前场景与哲学源文本并置：

```
  ┊ 「回环」 ← 虚无主义的循环 ← 尼采·永恒回归
  ┊ cf. 《从本有而来》§91
```

一行暗灰色的索引，不解释任何东西，只标注**坐标**。中等水平玩家由此获得一根线索去拉扯；专家看到它只会点头。

### 2c. 透明态（Transparent Mode） — φ ≥ 0.7

两层都消失。玩家看到纯净的原始世界文本。系统唯一的作用：提供**更激进的选项提示**，指向隐藏路径和深层结构。

### 2d. 术语的解蔽（Term Aletheia）

当玩家**首次遭遇**关键术语时，处理取决于 φ：

**φ < 0.3 — 具身化：** 术语不被定义，而是被**转化为体验**。当"Aufhebung/扬弃"首次出现时，不加注释；但下一个世界回应中，3322 号 AI 的行为本身**演示了扬弃**——先否定自己上一个判断，保留其中某部分，再提升到新理解。玩家通过 AI 的示范"看见"扬弃，而非被告知。

**0.3 ≤ φ < 0.7 — 并置：** 术语旁出现原文片段碎片：

```
  ┊ 扬弃 Aufhebung ← 「否定之否定」
  ┊ ← 黑格尔《逻辑学》I, 本质论, 根据
```

**φ ≥ 0.7 — 无处理：** 术语以原样出现，无标注。

## 3. 光谱实例：Echo 章节的三种体验

### 玩家 A（好奇少年，φ = 0.15）

- 中央叙事：标准文本 + **AI 独白追加段**
- 左侧 doctrine 区：逐条缓慢浮现（间隔 5 秒，非一次性展示）
- suggestions 栏：行动性提示（"试试摸一下墙壁""仔细听"）

### 玩家 B（读过哲学导论，φ = 0.5）

- 中央叙事：标准文本，**无 AI 独白**
- 左侧：正常速度 + 底部暗灰互文引用
- suggestions 栏：概念性提示（"思考回环与永恒回归的关系"）

### 玩家 C（哲学研究者，φ = 0.85）

- 中央叙事：**纯净文本**，无附加
- 左侧：doctrine 一次性完整展示，无 traces
- suggestions 栏：多出隐藏的 ritual 级选项（"追问回环本身的存在论地位"），或完全空白——系统信任玩家

## 4. 与 Lens 系统的关系

解蔽系统**不是一个 lens**，而是 lens 的**前置调制器**。它决定每个 lens 在当前 φ 值下的**解析度**：

- 低 φ + 某 lens → 看到表层（"这里有矛盾"）
- 高 φ + 同一 lens → 看到完整结构（否定-保留-提升的三重动态）

同一个 lens 在不同 φ 下，呈现的文本**密度和抽象层级不同**——不是内容不同，而是**同一内容的不同景深**。

---

## 5. 退隐机制（Progressive Withdrawal）

`layerDepth` 从 3 开始（新玩家），每当 φ 跨过阈值时递减：

| φ 阈值 | layerDepth | 效果 |
|---|---|---|
| φ 过 0.3 | 3 → 2 | 回声层消失 |
| φ 过 0.5 | 2 → 1 | 互文引用变为仅场景转换时闪现一次 |
| φ 过 0.7 | 1 → 0 | 完全透明态 |

**一旦降低，永不回升。** 这与"永恒回归"形成辩证关系：世界在轮回，但玩家的理解不可逆地深化。

解蔽系统的退隐本身就是一种 **Aufhebung** —— 它否定了自身的必要性，保留了它曾开启的理解，将玩家提升到不再需要脚手架的境地。
