# v2 异步联机痕迹系统设计

> draft · 2026-04-11 · 待作者确认

## 设计原则

- **纯异步** —— 无实时多人，玩家永远不会"同时在线"
- **最小基础设施** —— 可仅用 git bare repo / 共享文件夹 / S3 运行，无 MMO 后端
- **痕迹来源模糊** —— 你永远无法确定一条痕迹来自另一个玩家、前世的自己、还是系统本身
- **痕迹可误导** —— 并非所有痕迹都有帮助，低意识形态状态的玩家也会留痕
- **无身份** —— 无用户名、无个人主页，只有坐标和标记

---

## 1. 三种痕迹原语

### 1a. 铭文（Inscription） — 键 `G`（graffiti）

玩家在任意文本段落旁书写短文。

- **限制：最多 17 个字符**（汉字或 ASCII），不可包含换行
- 17 对应海德格尔 "Vom Ereignis" 的字母数
- 输入后不可编辑、不可删除
- 每个位置每轮回仅 1 条

### 1b. 印记（Seal） — 键 `M`（mark）

无文字，仅留下一个符号 `◈`。表示"某人曾在此驻留"。不附带任何语义——纯粹的在场证明。每个位置每轮回只能留一次。

### 1c. 路径残影（Afterimage） — 自动记录

玩家完整轮回的移动路径被自动压缩为序列（如 `B-E-P-F-L-G-O-D-B`），附带各节点停留时长。无需主动操作。

## 2. 存储与同步

**最小方案：一个 bare git repo。**

```
~/.aporia/
├── trace/           # 本地痕迹（已有）
├── world/           # 同步目录（git clone）
│   ├── inscriptions/
│   │   ├── echo/
│   │   │   └── 3a7f.json    # 以 content hash 命名，无可追溯身份
│   │   └── foresight/
│   ├── seals/
│   │   └── echo.jsonl       # 每章一个文件，append-only
│   └── afterimages/
│       └── cycle-3a7f.json
└── sync.lock
```

**单条铭文数据格式：**

```json
{
  "v": 1,
  "ch": "echo",
  "pos": "text:parmenides:3",
  "coord": "3312",
  "cycle": 7,
  "t": 1712000000,
  "body": "谬误之路也是路",
  "lens": "$-1-4-2"
}
```

**同步策略：** 启动时 `git pull --rebase`，轮回结束时 `git add && commit && push`。冲突不可能发生——文件以 content hash 命名，只增不删。无服务器时退化为纯本地模式。

也可用任意 append-only 存储替代 git：S3 bucket、共享文件夹、甚至一个 Telegram channel。

## 3. 痕迹的呈现

**核心原则：痕迹与系统文本在视觉上无法完全区分。**

```
┌─ ECHO ─────────────────────────────────────────────┐
│                                                      │
│  你在回环中行走。同一条走廊。同一面墙。               │
│                                                      │
│  "存在者存在，不存在者不存在"                         │
│                          —— 巴门尼德斯 ◈◈◈           │
│                                                      │
│   ┄ 谬误之路也是路                    [3312·c7]      │
│   ┄ 但谁能确定                        [2241·c3]      │
│                                                      │
│  ∞ "虚无并非什么也不是..."                            │
│                                                      │
│  ◈                                                   │
│                                                      │
│                                 [N] [S] [E] [W]      │
│                                 [$] [G] [M] [R]ead   │
└──────────────────────────────────────────────────────┘
```

**视觉规则：**

- 铭文以 `┄` 前缀 + dim 色（灰色/暗淡色）显示，区别于系统文本的正常亮度
- 铭文后的 `[3312·c7]` 表示坐标和轮回数，不显示任何用户名
- `◈` 印记聚集在文本段落旁——多个印记排列为 `◈◈◈`，暗示多人曾驻留
- 路径残影不直接可见，但影响**章节的"气氛词"**：若大量残影在 Echo 停留极短时间，该章节标题旁浮现 `（匆忙）`；若停留极长则显示 `（沉思）`

**出现频率控制：** 每个位置最多同时显示 **3 条铭文 + 5 个印记**。选取算法：优先显示与当前玩家坐标**汉明距离为 1-2** 的痕迹（既非完全相同也非完全陌生的意识形态）。

## 4. 坐标对痕迹的影响

| 坐标特征 | 痕迹效果 |
|---|---|
| **1-1-x-x** | 铭文被系统自动截断为前 8 字符，后半消隐为 `░░░` — 科学实在论的表达本身是有限的 |
| **x-x-x-4**（D4=泰然任之） | 铭文不显示坐标标签 `[????·c?]`，完全匿名 — 无目的者不留身份 |
| **4-4-4-4** | 铭文以正常亮度显示（与系统文本无法区分），且不标注 `┄` 前缀 — 绝对超越者的话语融入世界本身 |
| **3-3-x-x**（观念论域） | 铭文可**回应**其他铭文（形成 1 层深的线程），但回应同样受 17 字符限制 |
| **D1 差距 ≥ 2** | 痕迹对观看者显示为乱码 `▓▒░` — 意识形态距离过远，不可读 |

## 5. 痕迹衰变

衰变不按现实时间，按**世界轮回数**计。

```
寿命 = base_cycles × coord_weight

base_cycles:
  铭文   = 12 轮回
  印记   = 7 轮回
  残影   = 3 轮回

coord_weight:
  sum(coord_digits) / 10
  例：4444 → 16/10 = 1.6 → 铭文存活 19 轮回
  例：1111 → 4/10  = 0.4 → 铭文存活 4 轮回
```

**衰变的视觉表现：**

| 寿命阶段 | 表现 |
|---|---|
| 100-70% | 正常 dim 色 |
| 70-30% | 字符开始随机替换为 `·`，如 `谬误·路也·路` |
| 30-0% | 仅剩 `·····` 轮廓，最终消失 |

**例外：** `∞` 标记的文本旁的铭文**永不衰变** — 已被辩证穷尽的位置成为永恒遗迹。

## 6. 铭文交互流程

```
按下 [G]
  ↓
┌─ 铭文 ──────────────────────┐
│                              │
│  位置: echo / parmenides:3   │
│  你的坐标: 3322 · 轮回 #4   │
│                              │
│  > 谬误之路也是路_           │
│                   [12/17]    │
│                              │
│  [Enter] 刻入  [Esc] 放弃   │
└──────────────────────────────┘
```

刻入后不可撤回，本轮回内在同一位置不可再次铭写。

**回应机制**（仅 D1 ≥ 3 坐标可用）：光标移至一条已有铭文上按 `G`，铭文成为回应。显示时缩进一层：

```
│   ┄ 谬误之路也是路                    [3312·c7]      │
│     ┄ 路在走你                        [3341·c9]      │
```

回应链最大深度为 1 — 不是论坛，是墙上的涂鸦与涂鸦旁的涂鸦。

## 7. 反滥用机制

**无审核、无举报——通过机制本身约束：**

| 机制 | 效果 |
|---|---|
| **17 字符上限** | 物理上限制垃圾内容量 |
| **每位置每轮回仅 1 条** | 无法刷屏 |
| **无身份** | 没有"粉丝"动机 |
| **衰变** | 垃圾内容自动消失；低坐标的铭文（coord_weight 低）衰变极快 |
| **汉明距离过滤** | 玩家只能看到意识形态"附近"的痕迹，trolling 内容被自然隔离到低坐标区域 |
| **4444 融入世界** | 只有真正完成意识形态跃迁的玩家才能写出与世界不可区分的文字——这是最高形式的"权限" |
| **铭文不可删除** | 作为自身行动的承担——刻下即永恒（直到衰变），这本身就是哲学性的约束 |

---

## 8. 最终效果

世界中弥漫着半可读的、来源不明的文字碎片。你不知道 `·····也是·` 是另一个玩家三轮前写的，还是系统生成的诗歌残片，还是上一世的你留下的。

这正是永恒轮回的体验——一切都已发生过，一切标记都在衰变，但新的标记不断被刻下。世界是一面不断被书写又不断风化的墙。
