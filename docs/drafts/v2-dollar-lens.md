# v2 $ 系列 → 透镜（Lens）系统设计

> draft · 2026-04-11 · 待作者确认

## 核心定位

每个 $ 节点 = **透镜（Lens）**——不是能力或状态，而是一种**认知视角**。玩家激活某个透镜后，同一段游戏文本/空间会呈现不同的意义层。

直接实现 "gaming = studying" 的设计理念：同一段荷尔德林诗句，透过 `$-1-1-1 NIHILIZED BEING` 看到的是虚无的面向，透过 `$-1-3-2 PURE REFLECTION` 看到的是反思的面向。

## 三层游戏语法

| 层级 | 编码格式 | 游戏功能 | 解锁方式 |
|---|---|---|---|
| **大域** | `$-1-$-$` / `$-2-$-$` | 世界的两个本体论阶段 | `$-1` 在前四章（Beginning → Leap）可用；`$-2` 在后四章（Grounding → Last God）解锁 |
| **中域** | `$-X-Y-$` | 透镜族群，同族共享一种"观看方式" | 在对应章节中完成足够阅读量后获得 |
| **叶节点** | `$-X-Y-Z` | 具体透镜，可装备 | 在特定文本段落中做出正确的辩证判断后获得 |

### 大域的分裂点

`$-1` 对应《逻辑学》存在论 + 本质论（直接性的世界）。`$-2` 对应概念论 + 理念论（中介了的世界）。

**Leap（跳跃）**是从 `$-1` 到 `$-2` 的**断裂点**——玩家必须在此完成从本质到概念的跃迁。具体而言，只有在前瞻空间中激活过 `$-1-3-4 THE GROUND` 透镜的玩家，才能触发跳跃通道中的 `$-2` 大域解锁。

## $ 系列与八章的亲和映射

每章有 2-3 个**亲和透镜**——在该章中使用亲和透镜可解锁隐藏文本和路径。

| 章节 | 亲和透镜 | 理由 |
|---|---|---|
| **Beginning** | `$-1-1-1 NIHILIZED BEING` | 纯有即纯无，开端的空白 |
| **Echo** | `$-1-4-2 THE APPEARANCE ITSELF` | 现象的回环就是回响 |
| **Playing-forth** | `$-1-2-$` 整族 | 符号系统对应传送的中介功能 |
| **Foresight** | `$-1-3-$` 整族 | 本质论的先行把握 |
| **Leap** | `$-1-3-4 THE GROUND` → `$-2-1-$` | 从根据跃入绝对者；跳跃即 $-1 到 $-2 的断裂 |
| **Grounding** | `$-2-1-3 CAUSALITY` + `$-2-1-4 RECIPROCITY` | 根据问题的核心：因果与交互 |
| **Ones to Come** | `$-2-2-$ CONCEPTION` | 概念-判断-推理 = 将来者的自我构成 |
| **Last God** | `$-2-3-$ OBJECTIVITY` | 机械论-化学论-目的论的客观世界（最后之神所掠过的） |
| **Seyn (→ 回到 Beginning)** | `$-2-4-3 THE ABSOLUTE IDEA` | 绝对理念通达存有 |

## $ 系列与四维矩阵的耦合

玩家的四位坐标决定**可见透镜范围**，使用透镜**反向修改坐标**。

### 坐标 → 透镜（读取方向）

| 坐标维度 | 影响 |
|---|---|
| D1 存在样态 | 决定 `$-X` 大域的可见性：D1 ≤ 2 只能看到 `$-1`；D1 ≥ 3 可看到 `$-2` |
| D2 真理结构 | 决定 `$-X-Y` 中域的解锁速度（真理观越高，中介越透明，解锁越快） |
| D3 时间性 | 决定透镜叠加上限：D3=1 仅装备 1 个透镜；D3=4 可同时叠加 3 个 |
| D4 实践姿态 | 决定透镜使用后是否**永久保留**：D4=4（泰然任之）时透镜不被消耗 |

### 透镜 → 坐标（写入方向）

频繁使用某族透镜会推动对应维度坐标变化：

- 大量使用 PURE THINKING 族 → D1 向 1 移动
- 大量使用 ESSENCE 族 → D1 向 4 移动
- 大量使用 CONCEPTION 族 → D2 向 2（融贯）移动
- 混合使用多族 → D3 向 4（瞬间）移动

**双向耦合**：坐标决定可用透镜，透镜使用又改变坐标。玩家不是"选择"自己的意识形态，而是在使用透镜的过程中**不自觉地被塑造**。

## 玩家操作

### 键位

| 键 | 功能 |
|---|---|
| `$` | 打开/关闭透镜树（TUI 树形菜单） |
| `↑↓` | 导航透镜层级 |
| `Enter` | 装备选中透镜 |
| `Tab` | 切换已装备的多个透镜 |
| `R` | 阅读当前位置文本（阅读量是进度的核心计量） |
| `J` | 判断（Judgement）——对当前文本做辩证判断，对/错都推进坐标变化 |
| `?` | 查看当前四位坐标和已解锁透镜列表 |

### TUI 呈现

```
┌─ ECHO ──────────────────────────────────────────┐
│                                                   │
│  [$-1-3-2 PURE REFLECTION]     你在回环中行走。   │
│                                 同一条走廊。       │
│  ┌ ESSENCE ──────┐              同一面墙。         │
│  │ ◇ SHINE       │              但墙面上的裂纹     │
│  │ ◆ REFLECTION ←│              似乎在映照你       │
│  │ ◇ ESSENTIALITY│              自己的步伐。       │
│  │ ◇ THE GROUND  │                                │
│  └───────────────┘              [N] [S] [E] [W]   │
│                                 [$] 透镜  [R]ead  │
├───────────────────────────────────────────────────┤
│ "...映像在自身中的映现不是对自身的规定..."          │
```

- `◆` = 当前装备的透镜
- `◇` = 已解锁未装备
- 未解锁透镜不显示（除非是痕迹层残留，见下）

## 轮回中的透镜痕迹

每次轮回（从 Last God 回到 Beginning）时：
- 所有透镜被清空
- 坐标被重置

但系统保留一个**痕迹层（trace layer）**：上一轮使用过的透镜在新一轮中会以暗色 `◇` 显示——未解锁但可见——提示玩家"这里曾有什么"。

### `∞` 标记

当玩家在**三次轮回中**对同一文本用**三个不同透镜**进行过阅读，该文本会永久显示一个 `∞` 标记——表示它已被"辩证地穷尽"。

收集足够的 `∞` 标记是通达 `$-2-4-3 THE ABSOLUTE IDEA` 的隐藏条件。
