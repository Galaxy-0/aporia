# v2 $ 透镜系统 x 八章空间 · 详细交互流设计

> draft · 2026-04-09 · 交互设计稿

---

## 1. 阅读流 (`R`)

按下 `R` 后，当前位置的文本段落进入**阅读态**：屏幕中央区域清除选项和导航，仅保留文本本身，底部显示一条细的进度线 `───────░░░░░`。

**充分阅读的判定**采用**滚动深度 + 驻留时间**双因子：

- 文本被分为若干**可视帧**（每帧约 4-6 行）。玩家用 `↑↓` 或 `Space` 翻动。
- 每帧需停留 **≥ 3 秒**才计为"已读"（底部进度线对应帧会从 `░` 变为 `█`）。
- 全部帧标记为已读 → 进度线完成 → 底部出现 `◆ 已充分阅读` 提示，持续 1.5 秒后自动消退。
- 该文本段落 ID 被写入 `readFragments[]`。

**未读完即退出**（按 `Esc`）：进度保留，下次 `R` 从上次位置继续。不触发 foresightReads 计数。

**特殊**：Foresight 章的阅读计数 (`foresightReads`) 直接关联 Leap 解锁——需要在 Foresight 中充分阅读 **≥ 4 段文本**，`leapReady` 才翻为 `true`。

## 2. 判断流 (`J`)

按下 `J` 后，在已充分阅读的文本下方展开**判断界面**：

```
┌─ JUDGEMENT ─────────────────────────────┐
│                                          │
│  "映像在自身中的映现不是对自身的规定"    │
│                                          │
│  此句之核心张力在于：                    │
│                                          │
│  [A] 映现否定了规定 ── 本质先于现象      │
│  [B] 映现即是规定 ── 现象就是本质自身    │
│  [C] 两者不可分割 ── 否定本身即运动      │
│                                          │
│           ◇ 你的判断改变你自身 ◇         │
└──────────────────────────────────────────┘
```

**辩证判断的核心规则：没有"对错"，只有"方向"。**

- 每个选项对应不同的**坐标推力向量**。例如选 [A] → D1 向"本质"(4)偏移；选 [B] → D1 向"质"(1)偏移；选 [C] → D3 向"瞬间"(4)偏移。
- 选择后，屏幕不显示"正确/错误"，而是显示一行**回应文本**（约 15 字），反映该判断对你自身的改变："你看到了分裂。分裂也看到了你。"停留 2 秒后消退。
- **叶节点透镜解锁条件**：在特定文本上、装备特定中域透镜、选择与该透镜亲和的判断方向 → 解锁对应叶节点。玩家不被告知条件，只在解锁发生时才知晓。

## 3. 透镜切换 (`Tab`)

在阅读态或普通浏览态中按 `Tab` 切换已装备透镜时：

**视觉过渡：硬切 + 残像。** 非平滑过渡——屏幕内容瞬间替换（模拟认知范式转换的不连续性），但旧文本的最后 2 行会以暗灰色（dim）残留 0.8 秒后淡出，形成**短暂的双层叠影**。

```
  切换前（$-1-3-2 PURE REFLECTION）:
  "墙面上的裂纹似乎在映照你自己的步伐。"

  切换瞬间（$-1-1-1 NIHILIZED BEING）:
  "这里什么都没有。连裂纹也是空的。"
   ░░ 墙面上的裂纹似乎在映照你自己的步伐。░░  ← dim残像,0.8s消退
```

顶部透镜标签同步切换：`[$-1-3-2 PURE REFLECTION]` → `[$-1-1-1 NIHILIZED BEING]`，切换时标签闪烁一次（inverse video，50ms）。

若 D3 ≥ 3（时间性允许叠加多透镜），`Tab` 循环切换；`Shift+Tab` 反向。当前活跃透镜以 `◆` 标记。

## 4. 透镜获取

### 中域解锁

在某章节中累计完成足够阅读量（充分阅读 2-3 段文本）→ 触发中域解锁。

**解锁瞬间的呈现**：屏幕底部的引文区短暂替换为：

```
├───────────────────────────────────────────┤
│         ◇ ESSENCE 族透镜已显现 ◇          │
│   $-1-3-$  ·  本质的观看方式向你敞开      │
│                                  [2.5s]   │
├───────────────────────────────────────────┤
```

无需玩家确认，2.5 秒后自动回到正常界面。透镜树中该族从不可见变为可见（`◇` 状态）。

### 叶节点解锁

通过判断流中特定条件触发。解锁更加隐秘——仅在透镜树内对应位置**从空位凝现为 `◇`**，伴随该行文字以逐字打印方式显现（每字 80ms），无全屏提示。玩家需要自己打开 `$` 树才会注意到。

## 5. 亲和共振

当玩家在某章使用该章的亲和透镜阅读文本时：

**隐藏文本的揭示方式：逐行渗透。** 原本不可见的隐藏行以 dim 色从文本段落的间隙中"渗出"——先显示为 `░░░░░░░░░` 形状的灰块（0.5s），再逐字替换为实际文字（每字 60ms），最终以正常亮度呈现。

```
  普通阅读:
  "你在回环中行走。同一条走廊。"

  装备亲和透镜 $-1-4-2 THE APPEARANCE ITSELF 后:
  "你在回环中行走。同一条走廊。"
  ░░░░░░░░░░░░░░░  →  "但走廊在走你。"    ← 隐藏行渗出
```

亲和共振还附带效果：阅读该段时进度线速度加倍（驻留要求降至 1.5 秒/帧），暗示透镜与文本之间的"谐振"。文本段落左侧出现一条竖线标记，从 `│` 变为 `║`（双线），表明亲和态激活。

## 6. `∞` 标记与中间态

### 中间态跟踪

系统维护每段文本的**透镜阅读历史**（跨轮回持久化至 `~/.aporia/trace`）。

- 第 1 次用某透镜充分阅读 → 文本 ID 旁无特殊标记
- 第 2 次用**不同透镜**充分阅读（可跨轮回）→ 文本 ID 旁出现 `◇◇` 标记（两个空心菱形），在阅读态中文本标题行右侧显示
- 第 3 次用**第三个不同透镜**充分阅读 → `◇◇` 变为 `∞`

### `∞` 显现的瞬间

第三次充分阅读完成时，进度线不显示 `◆ 已充分阅读`，而是：

```
         ∞

  这段文字已被辩证地穷尽。
  它不再属于任何单一的观看。
```

全屏居中显示 3 秒，文字以极慢速逐字打印（每字 150ms）。之后回到正常界面，该文本段落的标题永久附带 `∞` 符号。

### 接近提示

当玩家处于 `◇◇` 状态并装备第三个未用过的透镜进入该文本时，文本标题行的 `◇◇` 会以 0.5Hz 频率缓慢闪烁——不解释原因，仅作为微弱的视觉提示。

## 7. 坐标变异反馈

透镜使用改变坐标时，采用**延迟 + 间接**的反馈策略：

**不即时通知。** 坐标变化在内部立刻生效，但 UI 上的坐标显示（通过 `?` 查看）在变化后的 **下一次场景转换时**才更新。玩家在同一章节内不会看到坐标跳动。

**间接暗示**：坐标变化后，下一次打开透镜树 (`$`) 时，可能会发现：
- 某个原本可见的透镜变为不可见（坐标下降导致可见范围收缩）
- 某个原本不可见的透镜变为可见（坐标上升导致新透镜可达）
- 透镜树标题行显示的大域从 `$-1` 变为 `$-1 / $-2`（D1 升至 ≥ 3）

**唯一的直接提示**：当 D1 从 2 跃升至 3、导致 `$-2` 大域首次可见时，屏幕底部引文区闪现：

```
│  第二重世界在你的观看中裂开了一道缝。      │
```

持续 2 秒，不可交互。这是整个游戏中坐标变化唯一一次被直接表达的时刻。

## 附：键位总表与状态机

```
  普通态
    ├─ $ → 透镜树态（↑↓ 导航，Enter 装备，Esc 关闭）
    ├─ R → 阅读态（↑↓/Space 翻页，Esc 退出）
    │       └─ J → 判断态（A/B/C 选择 → 回到阅读态）
    ├─ Tab → 切换装备透镜（不改变态）
    ├─ ? → 状态面板（坐标 + 透镜列表 + ∞ 计数，Esc 关闭）
    └─ N/S/E/W/↑↓←→ → 空间移动
```
