# v2 玩家坐标生成系统设计

> draft · 2026-04-11 · 待作者确认

## 设计原则

- **全程无"请选择"字样**——玩家不觉得在做测试，而是在经历开场
- **任何输入都合法**——系统永远不说"无效输入"，一切都被吸纳
- **不可逆推**——玩家事后无法精确反推"我做了什么导致这个数字"
- **耗时约 90 秒**——四个场景各约 15-20 秒，加上过渡动画
- **坐标差异来源**：自由文本 + 反应时间 + 行为模式，三重混合保证分散性

---

## 一、首次进入：「呼唤」(Anruf)

### 屏幕一：沉默

玩家启动游戏后，终端全黑，停顿 3 秒。然后逐字显示：

```
你已经在这里了。
```

停顿 2 秒。屏幕清空。

### 屏幕二：四次「照面」(Begegnung)

系统不提问，而是**呈现四个场景**，每个场景对应一个维度。玩家不知道自己在被"测量"。

---

#### 第一照面 · D1 存在样态："什么在"

屏幕显示一段文字，缓慢打出：

```
    一棵树倒在无人的森林里。

    ░░░░░▓▓▓░░░░░
    ░░░▓█████▓░░░
    ░░░░░▓█▓░░░░░
    ░░░░░░█░░░░░░
    ▄▄▄▄▄▄█▄▄▄▄▄▄

    _
```

光标闪烁，等待输入。玩家可以打任何内容——一个字、一句话、或直接按回车。

**映射规则：**

| 行为 | D1 值 | 对应 |
|---|---|---|
| 直接按回车（沉默） | 1 | 质：纯粹存在，前反思 |
| 输入涉及"声音/听"相关 | 2 | 量：感性显现 |
| 输入涉及"树/存在/有没有"相关 | 3 | 度：概念把握 |
| 输入超过 20 字符或含问号 | 4 | 本质：辩证反思 |
| 未命中任何规则 | `bytes(input) mod 4 + 1` | 隐式分配 |

---

#### 第二照面 · D2 真理结构："如何显"

```
    下面两段话，一真一假。或者都真。或者都假。

    A │ 这个游戏已经开始了。
    B │ 你正在做选择。

    _
```

**映射规则：**

| 输入 | D2 值 | 对应 |
|---|---|---|
| "A" | 1 | 符合：揭蔽/aletheia |
| "B" | 2 | 融贯：adequatio |
| 同时提及两者或输入"都" | 3 | 去蔽：辩证过程 |
| 其他任何内容 | 4 | 裂隙：建构 |

---

#### 第三照面 · D3 时间性："如何在时间中"

```
    ──────────────────────────
    你从哪里来到这个终端窗口？
    ──────────────────────────
    _
```

完全开放。**映射基于回复速度**：

| 反应时间 | D3 值 | 对应 |
|---|---|---|
| 0-3 秒 | 1 | 当前化：瞬间反应，沉浸当下 |
| 3-8 秒 | 2 | 保持：有所思量 |
| 8-20 秒 | 3 | 先行：向将来筹划 |
| 20 秒以上或空回车 | 4 | 瞬间：时间外/永恒 |

---

#### 第四照面 · D4 实践姿态："如何行"

```
    这是最后一扇门。

    ████████████████████████
    ████████████████████████
    ████████░░░░████████████
    ████████░░░░████████████
    ████████████████████████

    _
```

**无任何提示。**纯粹看玩家做什么。

| 行为 | D4 值 | 对应 |
|---|---|---|
| 输入"开/open/进/enter"等动作词 | 1 | 服从：直接行动 |
| 输入问句 | 2 | 抉择：审慎探问 |
| 输入多行或长文本 | 3 | 创制：诠释介入 |
| 30 秒无输入，系统自动推进 | 4 | 泰然任之：无为 / Gelassenheit |

---

### 屏幕三：坐标显现

屏幕清空。缓慢显示：

```


            ·

          3 3 2 2

            ·


    这是你的位置。不是你选的。
    是你带来的。

```

停顿 3 秒，进入游戏（Beginning 章节）。坐标存入 `~/.aporia/trace` 文件。

---

## 二、返回者：「永恒回归」(Ewige Wiederkehr)

当 `~/.aporia/trace` 存在时，系统读取上一轮的**终局坐标**（非初始坐标）。

### 开场变化

```
    ……你又来了。

    上一次，你走到了 ████。
    但那条路已经塌了。
```

（`████` 处显示上轮终局坐标，但用方块遮盖——玩家只看到轮廓。）

### 四次照面仍然发生

映射规则不变，但最终坐标受上轮终局坐标**偏移**：

```
new_digit = (this_round_raw + prev_final_digit) mod 4 + 1
```

这意味着：你无法回到完全相同的起点，但旧的你会拉扯新的你。

### 显现措辞变化

```
          2 4 1 3

    你以为自己忘了。身体记得。
```

### 痕迹文件

`~/.aporia/trace` 追加新记录，保留所有历史轮次，形成一条**回归螺旋**：

```
# ~/.aporia/trace
cycle:1  init:3322  final:4231  ts:2026-04-11T14:30:00
cycle:2  init:2413  final:3344  ts:2026-04-12T21:15:00
cycle:3  init:1232  final:...
```

## 三、与其他系统的接口

| 系统 | 接口 |
|---|---|
| **四维矩阵** | 坐标生成直接产出四位数，对应 D1-D4 |
| **$ 透镜** | 初始坐标决定首轮可见透镜范围 |
| **八章空间** | 坐标决定 Beginning 章节的初始文本呈现 |
| **轮回痕迹** | `trace` 文件同时服务于坐标生成和透镜痕迹层 |
