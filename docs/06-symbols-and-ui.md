# 06 · 符号 · 视觉 · UI · 玩家引导

## 6.1 符号以及文字

借用关于《从本有而来》的启示性文本，配合黑格尔《逻辑学》的整体流程，再加之以**荷尔德林的诗的碎片**分布在空间的各个部分，而呈现在玩家的第一人称 UI 界面上。

### UI 布局

UI 本身结构和放置部分不作变更，其内容随流程区域的变更而改变。大致分为三个区块：

| 区块 | 内容 |
|---|---|
| **顶部** | 玩家所在的区域名称 |
| **左侧** | 相关的哲学主题 |
| **下侧** | 类似字幕的表示：阐释或诗歌一类 |

## 6.2 视觉色彩

> 整体的空间视觉基本呈现为**纯色和纯光影动态**为主，去除了不必要的各类强对比高饱和色彩搭配，由此着重突出关于概念和形而上的部分。**视觉的重要性必须被视为不重要**，这是设计视觉表现的整体思路。

抽象的纯粹空间形式更符合哲学的基于文字符号/语言的思辨形式，凸显本身的抽象性哲学内核，空缺出玩家理解和思考的空间。

### 原版技术实现

使用虚幻 5 游戏引擎，Lumen 动态光影渲染效果，采用**第一人称视角**，使玩家身临其境地投入到这个抽离、哲思的空间中。

玩家会经历：
- 从**狭窄空间到巨大空间**的"传送"
- 从**深度空间到巨大空间**的"信仰一跃"
- **动态水**的空间——这里突出的是诗歌的本有境地

配合物理动态（运动）和光影变化增加交互的趣味性，同时具备引导功能。

### 空间视觉清单（原稿）

- 开端 / Beginning 空间的视觉效果
- 传送 / Playing-forth 空间
- 前瞻 / Foresight 空间
- 跳跃通道 / Leap
- 建基 / Grounding 空间
- 将-来者 the Ones to Come 领域

## 6.3 玩家引导

玩家引导的设计经历过几轮迭代：

- **初代**：指示标作为持续的在玩家屏幕上显示 → 测试后发现并未达到其应有的效果
- **最终版**：在场景中会有固定的一个地点**悬浮着一个标示物**，其上指明关于这个空间状态的命名

例如：右侧的白边黑方块，其上写有 **Echo（回响）**。

### 第二种引导

借助**动态光影流动**来表现——玩家能去的地方就会有光影流动给予指示。

## 6.4 艺术家的游戏设计（杂项笔记）

### 视角性

- 人称化，复数化，主体性自由，多重视角
- **最大的张力在于**视角切换和人称转化
- 主体化模式和降临化方式，具身化方式

### 时空结构化

- 总体的一个**永恒回归**
- 具体的主体化现象与时空相对应：先验框架和结构了的主体视域相对应
- 目的论嵌入

### 巴别图书馆

符号学内嵌的空间场。

### 机制

- **遗忘和死亡**的机制
- 不同的出生点以及向着玩家所打开的不同视阈（一切的感知可能性及残留；概念所留下的印迹的可能）
- 视角：向内的窥视，第三人称的观看/大他者
- 所控制的主体变换，时间，有限性以及永恒回归
- 自动前进以及静止 / 两种静止：
  - 视角静止，主体可动
  - 主体静止，视角可动
- 符号学嵌入：对应的符号学点位的不同位置上所嵌入的一切 / 太一
- 时间性：倒置，扭转的场，或历史性——曾经或未来者改变过去之人，或者说看到过去，抑或看到未来
- 穿透性：时间的断裂——过去和未来被保留，或被禁闭/穿越回去
- 启示：不同视角下所呈现的 ID 编号是**唯一的**——每一个都代表了太一本身的分裂和崩解，但同时也是某种原初 S，被切割，自指涉，悖论和矛盾
- **彩蛋**植入，以及对于各种通路间的符号化视觉表现
- **注解性**：喷漆可注释，抑或更改或污染。过去和未来

### 世界之夜

> 这里更像是**世界之夜**，作为主体、视角、能力、目的的发生阶段——甚至时间和空间也在不断变更 ta 的形态。

所经历的所有可能性：
- 循环的
- 盲目的
- 到达终点
- 回到起点
- 断裂
- 掺杂有前世记忆的
- 找寻上一次的路径
- 探寻前人的痕迹
- 获得某种意义
- 或者仅仅是静止的关照

### 能力

两种移动、书写的能力、多视角的能力、符号获得的能力、记忆的能力和遗忘。
