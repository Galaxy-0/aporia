# 02 · 主义-世界（Ism-World）四分矩阵

## 起点

"主义-世界（ism-world）"作为一切的时间上的起点，是框架的最初表达，也是罗列各种主义样态的**矩阵场所**。

初衷：基于实在世界的摹本的简化版本，同时基于现实世界的多种意识形态/生存样态的维持，建立一种反身并被世界本身所定位的多种生存模型的已构建完毕的空间。

> 最为关键的游戏化考量的核心转变为：**分辨各种意识形态的根本原理是什么，以及它们之间的各种变化是如何触发的**，这个转变的发生学是否可以作为游戏化的真正节点。

## 四分法

以四分法的符号学拆分方式（**四元矩阵形式**）提出一些基本的形而上学立场。由这些划分方式，构造起一个动态的交互关系，并为更复杂的矩阵列扩充提出一些基本框架性的基石。

（其中以基本的四个辩证阶次作为基底的四分环节。）

### 2.1 四种不同的场域版本 / 存在论框架

| 编号 | 位格 | 特征 |
|---|---|---|
| a | **天** | 纯粹闭合的线性场域；接续性；教条 |
| b | **神** | 矛盾性场域 |
| c | **人** | 中心化，作为某个调和的矛盾 |
| d | **地** | 超越性，可变动的场域，轮转和调整，虚无，不可能性，虚无 |

### 2.2 四种不同的本体论 / 存在性内容的结构

- a) 闭合
- b) 矛盾
- c) 中心化，中介化
- d) 虚无，不可能性

### 2.3 四种主体现象视角 / 认识论

- a) 线性视角，单一，闭合
- b) 矛盾性，痛苦
- c) 调和，无目的的超越
- d) 变更，改变性

### 2.4 主体目的论 / 伦理学

- a) 唯一
- b) 自我矛盾的抉择
- c) 中心化，中介化
- d) 虚无，不可能性
